Yeah, I have left Lineman Wongnai since 14 March 2025, It was pretty awkward for me to say goodbye to 
every one. I think partly because it's my first time leaving for a new job. Even though, I think
it still is a good experience, because one day I will need to find a new opportunity anyway.

<br>

It has been around 5 months-ish and I think feels a little bit happier after working here, 
it's just a different kind of vibe though.

## Why though?

I think the biggest reason would be that I feels like I will not get better as an engineer if I stay at LMWN. 
Mostly, because I can't decide anything much by myself (or I just left way too fast to start anything lol).

<br>

And [Social Plus](https://www.social.plus/) seems to offer better opportunity, with mostly English working environment 
(I need to practice my English), and startup always have many things to work on. 

### Pros & Cons rants of LMWN POS team

##### Pros
- Good company benefits and salary.
- Performance evaluation is fair, but I still don't like it (need to boast more about my work which I don't like).
- I stated using Gitlab first time at LMWN and it feels great.
- Everyone in a company are great colleagues, especially my teammates.
- The job is not that hard, there're just way too much works.
- Trunk-Based feels so good.
- Working with Golang on production feels great too.

##### Cons
- I hate working with PHP7 :C, and pure Javascript without even JSDoc.
- Even though we have trunk-based but stil need to do 1 week code freezing for testing a release.
- I think there're no clear direction on software development made everyone confused.
- No local setup for most backends ;-; need to use shared environemnt for development which is always 
  a staging environment.
- Staging environment has way too many things that is not the same as production. (saw some weird bugs from this)
- AWS API Gateway suck without IaC. There are no actual usable history for deployments.

<br>

**What would I want do if I were to stay at the LMWN?**

I think I really wanna update every things e.g. PHP7 to PHP8 and improve developer experience when 
working on various repositories by adding proper unit tests, good CI (and add types to JavaScript repositories
via JSDoc or TypeScript migration).

## What's now?

Currenly working on many social media features at Social Plus (*old name Amity*).

- So much works to do, there're many features that we need to deliver and most of them is interesting.
- Have a chance to write some production-ready Rust code.
- Working with same colleagues from my intern time is so chill and I think I'm always able to express my concerns.
- Learned to use some new tools like [k9s](https://k9scli.io/) to check kubernetes deployments, back to 
  be a [MongoDB](https://www.mongodb.com/) boy, working with [Pub/Sub](https://cloud.google.com/pubsub/docs/overview) 
  and various [AWS](https://aws.amazon.com/) tools like Lambda, CloudWatch, etc, used [OpenSearch](https://opensearch.org/) 
  and also some [Neo4j](https://neo4j.com/).  

<br>

**Conclusion**
I think I started writing this short blog back in April, but I never finished it because I didn’t know what to write.
To conclude, I believe I made the right choice in changing my job to Social Plus.
Here, I’ve had the chance to develop many cool features, use various tools, and improve my English.
