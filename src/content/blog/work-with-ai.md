First off, I'm using [Claude](https://claude.ai/) every day to do my work and recently everything kinda just worked out 
and I do not know what I wanna do with programming anymore lol. I don't think I'll stop doing this 
kind of software engineer thing but how I would do it is already changing. Yeah I still read a lot of 
those AI-generated code and try to understand it line by line. But I think the energy I used to read 
those is dropping, and I knew it too cuz LLMs is way too good at producing an okayish code without 
any obvious flaws now.

<br>

Enough with the rants, the point of this blog is just I think I need to write more to train my brain 
to be able to still think in the AI era. And I'll just start with random things I wanna write XD.

### Tools I've used and are using
I'm still love using [NeoVim](https://neovim.io/) and tmux to do all my development works. I love 
this flow already and changing this will required so much energy so I think I'll keep using it.
Especially with the new addition **Claude Code!!**, nvim configuration never been easier, you can just  
tell claude to *"add oxfmt, oxlint for my nvim config"* and VOLA! everything is working fine. 

<br>

Previously, my company used the github copilot so I actually have used the [copilot-cli](https://github.com/features/copilot/cli) too, I think it's okay
but claude code is much better in my opinion. I don't know why, maybe it's because of their system prompt, 
harnesses, bla bla, who cares? (actually, I should care about it but I just do not have the energy to go 
down the rabbit hole). I've tried the [Pi](https://pi.dev/) too, cool thing but sadly cannot use with 
my company claude credits.

<br>

The skills I'm using 
- `/caveman` less text please, I don't want to read more bullshits.
- `/cavecrew` exploring tasks.

    write way too many comments.

<br>

And I think that's it. I like to keep it simple or maybe it's a skill issue that I cannot work 
with loop engineering blabla shits that seems to make my life harder haha.
